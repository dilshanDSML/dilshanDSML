### 🔍 AI Competitor Analysis Tool

An AI-powered competitor research application built with Python and Streamlit. Uses AI agents and web search to analyze competitors and generate structured business insights.

**Key Features:**
- 🌐 Automated web research on competitors' products, pricing, positioning, and reviews.
- 🤖 AI-powered competitor analysis and strategic recommendations.
- 💬 Multi-turn chat for asking follow-up questions about research findings.
- 📊 Comparison dashboard with summaries and detailed analysis.
- 📄 PDF report generation with executive summaries, competitor insights, and recommendations.
- 🔁 Retry support for failed competitor analyses.

**Tech Stack:** Python, Streamlit, AI Agents, LLMs, Web Search, fpdf2.
