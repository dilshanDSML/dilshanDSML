## ⭐ Featured Project: AI Competitor Analysis Tool

An AI-powered competitor analysis app built with **Streamlit** 🚀. Enter your company name and up to 4 competitors, and AI agents with real-time web search research each one. Then chat with the results and export a polished PDF report.

### ✨ Features

- 🔎 **Automated competitor research**: AI agents search the web for up-to-date info on products, pricing, positioning, and reviews
- 💬 **Multi-turn chat**: ask follow-up questions (pricing comparisons, threats, opportunities, strategy) with full conversation context
- 📊 **Results dashboard**: quick-glance comparison cards plus expandable full write-ups per competitor
- ⏳ **Live progress feedback**: see which competitor is being analyzed while agents run in the background
- 📄 **PDF export**: executive summary, per-competitor analysis, strengths/weaknesses, strategic recommendations, and the chat transcript
- 🔁 **Error handling with retry**: if one competitor's analysis fails, retry just that one instead of restarting the whole run

### 🧰 Tech

`Python` · `Streamlit` · `AI Agents + Web Search` · `fpdf2`

### 📂 Project Structure

```
.
├── app.py            # Streamlit UI: setup, analysis flow, results, chat, export
├── Agent.py          # AI agent logic: competitor research and chat functions
├── report.py         # PDF report generation
└── requirements.txt  # Dependencies
```

### 🚦 Getting Started

**Prerequisites:** Python 3.9+ and an API key for the LLM/search provider `Agent.py` is configured to use (set as an environment variable, e.g. in a `.env` file).

```bash
pip install -r requirements.txt
streamlit run app.py
```

### 🧭 Usage

1. 🏢 Enter your company name and a short description
2. 🎯 Add up to 4 competitors to analyze
3. 🚀 Click **Start Analysis** and watch live progress
4. 📊 Review the comparison cards and full analyses
5. 💬 Switch to **Chat** for follow-up questions
6. 📄 Go to **Export** to generate and download the PDF report
